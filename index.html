Open Liero Reloaded

This is the game's Flatpak repository. Install the final releases with

flatpak install --user https://openlieroreloaded.github.io/flatpak/stable.flatpakref

or the pre-releases too with

flatpak install --user https://openlieroreloaded.github.io/flatpak/beta.flatpakref

The game and your software centre update it from here. Releases: github.com/chvatma2/open-liero-reloaded/releases.
